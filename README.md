# UPI Fraud Detection System

## About the Project
A machine learning-based web application that predicts whether a UPI transaction may be fraudulent.

## Technologies Used
- Python
- Pandas
- Machine Learning
- Flask
- HTML and CSS

## Features
- Fraud prediction for UPI transactions
- Machine learning-based classification
- Simple web interface

## Project Files
- `app.py` - Main application
- `fraud_model.pkl` - Trained fraud detection model
- `encoders.pkl` - Saved encoders
- `train.py` - Training script
- `train_model.py` - Model training script
- `templates/` - HTML pages
- `static/` - Static files
- `requirements.txt` - Required Python packages

## Objective
To demonstrate how machine learning can help identify potentially fraudulent UPI transactions.
